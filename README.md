# بلاغ الحملة القومية للتطعيم — بطعم MR (إدارة قويسنا الصحية)

فولدر جاهز للرفع على **GitHub Pages** زي ما هو. مفيش سيرفر ومفيش أي إعداد.

---

## الرفع (3 خطوات)

1. على GitHub: **Add file → Upload files** → اسحب **كل الملفات اللي في الفولدر ده** (14 ملف).
2. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` · Folder: `/ (root)` → **Save**.
3. استنى دقيقة–دقيقتين → افتح `https://<حسابك>.github.io/<الريبو>/`

**الرابط اللي تبعته للوحدات:**
`https://<حسابك>.github.io/<الريبو>/unit.html`

---

## التحديث اليومي

بدّل ملف **`baseline.xlsx`** بملف اليوم الجديد (نفس الاسم بالظبط) → **Commit**.

> الاسم لازم يبقى `baseline.xlsx` — الصفحة بتدوّر عليه الأول.
> ولو سميته حاجة تانية، بيدوّر على أي ملف `.xlsx` في الريبو لوحده (لو الريبو عام).

**للتأكد إن كل حاجة تمام:** افتح `.../check.html` — بتقولك الشيت اتقرأ ولا لأ، وتاريخه إيه، وعدد الوحدات كام.

## ملاحظات

- **الموقع للقراءة بس:** الوحدات بتدخل أرقامها وتنزّل PDF على جهازها — مفيش أي حاجة بتترفع أو بتتخزن على السيرفر.
- **الافتح من رابط** (`https://` أو `http://`) — لو فتحت `index.html` بالدبل كليك، المتصفح بيمنع الصفحة تقرا
  ملف الشيت اللي جنبها (قيد CORS)، وهتقولك «مفيش شيت». افتح `check.html` لو حصل ده.
- **الشيت عام**: أي حد عنده الرابط يقدر ينزّله. لو ده مش مناسب، الطريقة الوحيدة هي سيرفر.
